## 📌 Executive Summary

**Älyviitta (Smart Auraviitta)** is an open-source, modular, solar-powered roadside beacon mesh network designed to eliminate wildlife-vehicle collisions (**Hirvikolari / Vision Zero**) on northern highways.

By replacing passive plastic snow-plow markers (*Auraviitta*) with intelligent 6-section modular beacons equipped with thermal sensors (Grid-EYE), Sub-GHz mesh radios, and 360° CIGS solar sleeves, Älyviitta creates a dynamic safety corridor for drivers.

---

## 🛠️ Key Engineering Features (v1.0 Specification)

* **6-Section Modular Architecture:**
  1. *Section 1:* Composite Ground Anchor / Anchor Socket.
  2. *Section 3:* Polyurethane Flex-Joint (vibration/snow-plow impact damper).
  3. *Section 3:* Red Body with LiFePO4 Low-Temp Battery Core (-40°C).
  4. *Section 4:* Protected Radio-Electronics & MCU.
  5. *Section 5:* Polycarbonate Dome with Directional Dual-Side RGB LEDs.
  6. *Section 6 (Master Top):* 360° Flexible CIGS Solar Sleeve + Grid-EYE Thermal Matrix.

* **Connectivity:** Mesh Network Sub-GHz (868 MHz) + NB-IoT Heartbeat Telemetry.
* **Smart Operation:** "Green Safety Corridor" at night → "1Hz Pulsing Red Alarm" locally (200m) upon moose detection.
* **Cost Efficiency:** ~€2,210 per 1 km (100 poles) vs €40,000 for traditional moose-fences.
